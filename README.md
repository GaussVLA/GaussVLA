# GaussVLA: Geometry-Aware Spatial Reasoning for Vision-Language-Action Model

Project page for **GaussVLA** (BMVC 2026).

- **Paper:** https://arxiv.org/abs/2608.24959 (includes the supplementary material)
- **OpenReview:** https://openreview.net/forum?id=IYv9sR4feE
- **Project page:** https://gaussvla.github.io/GaussVLA/

Every number and figure on the page is taken from the arXiv paper.

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Structure

```
index.html              # the whole page
static/css/index.css    # styles
static/js/index.js      # nav, sortable table, LIBERO-PRO heat cells, ablation toggles, lightbox, BibTeX copy
static/images/          # paper figures (framework, teaser, LIBERO, Meta-World, SO-101) and favicon
static/videos/          # LIBERO rollout clips
```
